# Análise de Código Java

## Descrição

A **Análise de Código Java** é uma ferramenta de apoio educacional desenvolvida para auxiliar professores no ensino de Ciência da Computação. Esta extensão permite a análise inteligente do código dos algoritmos Java produzidos pelos estudantes, identificando sinais de problemas de aprendizagem que vão além da simples correção e conceituação dos resultados.

## Funcionalidades

- **Análise de Código**: Envie o código Java para análise através do menu de contexto no Explorer do VSCode.
- **Identificação de Problemas**: A ferramenta utiliza IA para identificar possíveis problemas de aprendizagem nos códigos dos alunos, fornecendo feedback valioso para o processo educacional.
- **Resultados Imediatos**: Receba feedback instantâneo e construtivo para ajudar os alunos a melhorarem suas habilidades de programação.

## Uso

A utilização da ferramenta é livre e gratuita, porém está sujeita à disponibilidade de créditos da plataforma **OpenAI**.

## Instalação

1. Certifique-se de ter o [Visual Studio Code](https://code.visualstudio.com/) instalado.
2. Procure por "Análise de Código Java" na Marketplace do VSCode e instale a extensão.
